# インプット記録

読んだ本・記事・動画などの「インプット」を記録し、あとから **キーワード・日付・種類・タグ** で検索できる Web アプリ（PWA）です。

- **オフラインで動く** … アプリ本体は Service Worker でキャッシュ、記録は端末内（IndexedDB）に保存
- **Google ドライブに保存** … マイドライブの `InputLog/input-log.json` に全記録を保存
- **オンライン復帰時にまとめて同期** … オフライン中の追加・編集・削除は「未同期」として保持し、復帰時に自動で同期
- ビルド不要。HTML/CSS/JavaScript だけで、GitHub Pages などの静的ホスティングに置くだけで動きます

## 使い方

| 機能 | 内容 |
| --- | --- |
| 記録 | 日付・種類・タイトル・内容・タグ・URL を入力して保存 |
| 写真・動画 | 「＋ 写真・動画を追加」で複数添付（カメラ撮影も可）。写真は長辺2048pxに縮小、動画は元のまま。1ファイル500MBまで |
| キーワード検索 | スペース区切りで AND 検索。全角/半角、大文字/小文字、ひらがな/カタカナを区別しない。一致箇所をハイライト |
| 日付検索 | 開始日〜終了日、または「1週間 / 1か月 / 1年」ボタン |
| 絞り込み | 種類、タグ（タグをタップ） |
| 編集・削除 | 各記録の「編集」「削除」 |
| バックアップ | 設定 → JSON の書き出し / 読み込み |

スマホではブラウザの「ホーム画面に追加」でアプリとしてインストールできます。

## 同期のしくみ

1. 保存すると、まず端末内に書き込み「未同期」印を付けます（オフラインでも可）。
2. オンラインで Google に接続済みなら、保存の約1.5秒後・オンライン復帰時・アプリを開いた時・5分ごとに自動で同期します。
3. 同期では Drive のファイルをダウンロード → 記録ごとに **更新日時が新しい方** を採用してマージ → Drive にアップロードします。
   削除は「削除済み」の記録として残すので、他の端末にも削除が反映されます。
4. 複数端末で同時に書き込んだ場合は、アップロード直前に Drive 側の版を確認し、変わっていればやり直します。

> **注意:** サーバーを持たない構成のため、Google のアクセス許可（トークン）は約1時間で切れます。
> 切れた状態でオンラインに戻ったあと画面を最初にタップすると、自動で再接続を試みて未同期の記録をまとめて送ります
> （ポップアップが一瞬出ます。一度許可していれば、アカウント選択なしですぐ閉じます）。
> 自動で再接続できなかった場合は、画面上部の「Google ドライブに同期」ボタンをタップしてください。
> 再接続に失敗しても、端末内の記録や Drive のファイルとの紐づけは消えません。

## 写真・動画のしくみ

- 本体は端末内（IndexedDB）に保存するので、オフラインでも撮影・添付・表示できます。
- 同期のとき、文字の記録を先に送ってから、写真・動画を Drive の `InputLog` フォルダにアップロードします（動画のような大きいファイルは再開可能アップロード）。
- 別の端末では、記録は同期されますが、写真・動画の本体は「☁ 取得」ボタンを押したときにダウンロードします（通信量の節約）。取得した分は、その端末にも保存されます。
- 添付を外す・記録を削除すると、Drive 上のファイルも次回の同期で削除します。
- 添付のファイル名も検索の対象です。
- Google ドライブの容量（無料は15GBで Gmail・フォトと共有）を使います。動画のアップロードは Wi-Fi 推奨です。

## セットアップ

### 1. GitHub Pages で公開

1. このリポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、ブランチを選んで `/ (root)` を指定
2. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

### 2. Google ドライブ連携の設定（初回のみ）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. **API とサービス → ライブラリ** で「Google Drive API」を有効化
3. **OAuth 同意画面** を作成（ユーザーの種類「外部」、テストユーザーに自分の Google アカウントを追加）
   - スコープは `https://www.googleapis.com/auth/drive.file`（このアプリが作ったファイルにだけアクセスできる最小権限）
4. **認証情報 → 認証情報を作成 → OAuth クライアント ID**
   - 種類: 「ウェブ アプリケーション」
   - 承認済みの JavaScript 生成元: `https://<ユーザー名>.github.io`（ローカルで試すなら `http://localhost:8080` も）
5. 表示されたクライアント ID（`xxxx.apps.googleusercontent.com`）を、アプリの **⚙ 設定 → OAuth クライアントID** に入力して「Google に接続」
   - 全端末で入力を省きたい場合は `js/config.js` の `GOOGLE_CLIENT_ID` に書いておきます（クライアント ID は公開しても問題ない値です）

## ローカルで動かす / テスト

```bash
npm start   # http://localhost:8080 で起動
npm test    # 検索・マージ処理のユニットテスト
```

アプリのファイルを更新して公開するときは、`sw.js` の `CACHE` のバージョン（`input-log-v1` → `v2` …）を上げてください。

## ファイル構成

```
index.html            画面
style.css             スタイル（ダークモード対応）
sw.js                 Service Worker（オフライン用キャッシュ）
manifest.webmanifest  PWA 設定
js/app.js             画面の処理
js/core.js            検索・マージなどの純粋ロジック
js/db.js              端末内保存（IndexedDB）
js/drive.js           Google ドライブ API
js/sync.js            同期処理
js/media.js           写真・動画のヘルパー（縮小など）
js/config.js          OAuth クライアント ID（任意）
tests/                ユニットテスト
```
